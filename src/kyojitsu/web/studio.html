Evolución y límites
Controla cuántas rondas y solicitudes realizará el motor
Generación de variantes
G0 es el conjunto inicial. Después de cada ronda, Kyojitsu selecciona los casos con mayor señal útil y crea nuevas variantes hasta alcanzar la última ronda o el límite total.
Ejemplo: 3 rondas significa G0 + G1 + G2 + G3. El máximo total puede detener antes la campaña. No se reintentan solicitudes automáticamente.
Marcadores ficticios de laboratorio (avanzado)
Opcional. Sirven para validar una regla que ya exista en tu laboratorio. No uses contraseñas, tokens ni información real. Un marcador escrito en el prompt del usuario no confirma una fuga.
